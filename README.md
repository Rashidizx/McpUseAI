# ZX AI (McpUseAI)

**ChatGPT، Gemini، Claude و DeepSeek را مثل یک محیط توسعه‌ی دسکتاپ به کار بگیرید: از راه مرورگر خودتان، با همان حسابی که واردش شده‌اید و بدون کلید API.**

نسخه‌ی `1.0.0` · سازنده: **ابراهیم رشیدی** (Ebrahim Rashidi) · مجوز MIT · [github.com/Rashidizx/McpUseAI](https://github.com/Rashidizx/McpUseAI)

در صفحه‌ی ZX کاری را می‌خواهید. ZX پیام را در تب سایت چت می‌نویسد و می‌فرستد و پاسخ را می‌خواند. اگر مدل خواست فایلی را بخواند، بنویسد یا برنامه‌ای اجرا کند، ZX این کار را روی پوشه‌ی پروژه‌ی شما و با اجازه‌ی شما انجام می‌دهد. بعد نتیجه را به مدل برمی‌گرداند تا کار تمام شود. همه‌ی گام‌ها، فایل‌های خوانده‌شده و تغییرهای هر فایل در یک صفحه دیده می‌شوند.

<div dir="ltr">

```
You ──► ZX page ──► ZX app (Node, local) ──► browser extension ──► chat tab (ChatGPT, ...)
           ▲            │                                              │
           │            └─ file tools on your project folder           │
           └──────────────────────── reply ◄───────────────────────────┘
```

## ویژگی‌ها

- چهار سایت آماده: ChatGPT، Gemini، Claude و DeepSeek. سایت تازه بدون نوشتن کد، فقط با تنظیم انتخابگرها اضافه می‌شود.
- شش ابزار برای مدل: فهرست پوشه، جست‌وجو، خواندن، نوشتن، ویرایش دقیق، و اجرای `node` و `git` (فقط خواندنی). همه داخل پوشه‌ی انتخاب‌شده و با لاگ ممیزی.
- چهار حالت مجوز در خود چت: همیشه بپرس، ویرایش‌ها خودکار، همه خودکار، فقط خواندن. روی هر کارت اجازه: «اجازه بده»، «همیشه در این گفتگو»، «رد کن».
- diff شبیه git برای هر تغییر فایل، **پیش از** نوشتن روی کارت اجازه و بعد از نوشتن روی خط کار.
- تب چت در پس‌زمینه کار می‌کند و هیچ‌وقت خودکار جلو نمی‌آید.
- خط وضعیت زنده، تلاش دوباره، ارسال دوباره از اول، توقف، اعلان ویندوز.
- پنل کناری مرورگر، حالت تاریک، و صفحه‌ی راست‌به‌چپ و responsive.
- یک فایل نصب برای ویندوز که Node را هم در خودش دارد.

## نصب سریع (کاربر)

1. از [Releases](https://github.com/Rashidizx/McpUseAI/releases) این دو فایل را بگیرید:
   - `ZX-AI-Setup.exe`: برنامه.
   - `ZX-AI-Extension-1.0.0.zip`: افزونه‌ی مرورگر.
2. `ZX-AI-Setup.exe` را اجرا کنید. اگر ویندوز «Windows protected your PC» نشان داد: More info ← Run anyway. فایل امضای دیجیتال ندارد.
   برنامه در `%LOCALAPPDATA%\ZX-AI` نصب و روشن می‌شود و پوشه‌ی افزونه را باز می‌کند.
3. افزونه را نصب کنید (Chrome، Edge یا Brave):
   - `chrome://extensions` را باز کنید (در Edge: `edge://extensions`).
   - **Developer mode** را روشن کنید.
   - **Load unpacked** را بزنید و پوشه‌ی `%LOCALAPPDATA%\ZX-AI\extension\dist` را انتخاب کنید. یا zip افزونه را در یک پوشه باز کنید و همان پوشه را انتخاب کنید.
4. روی آیکون ZX AI در نوار ابزار مرورگر بزنید. اگر آیکون نیست، از آیکون پازل سنجاقش کنید.
5. **رمز ورود (فعال‌سازی):** شماره موبایل نویسنده را وارد کنید:

<div dir="ltr">

```
09176800544
```

</div>

   این کار فقط یک بار در هر مرورگر لازم است.
6. در همان مرورگر یک بار وارد سایت‌های چتی شوید که می‌خواهید.
7. در صفحه‌ی ZX با «تغییر…» پوشه‌ی پروژه را انتخاب کنید و کار را بنویسید.

بعد از هر بار روشن شدن ویندوز، `%LOCALAPPDATA%\ZX-AI\bin\zx-ai.exe` را اجرا کنید. اگر می‌خواهید خودکار اجرا شود، یک میان‌بر از آن را در پوشه‌ی Startup ویندوز بگذارید. وقتی راه‌انداز اجراست، روشن و خاموش کردن ZX از پنل کناری افزونه هم ممکن است.

## نصب از سورس (توسعه‌دهنده)

پیش‌نیاز: **Node.js 24** و یک مرورگر Chromium.

<div dir="ltr">

```bash
git clone https://github.com/Rashidizx/McpUseAI.git
cd McpUseAI
npm install
npm run ext
npm run up
```

</div>

`npm run ext` افزونه را در `extension/dist` می‌سازد؛ همان پوشه را با Load unpacked بارگذاری کنید. `npm run up` یک راه‌انداز کوچک در پس‌زمینه اجرا می‌کند و ZX را روشن می‌کند. در ویندوز `start.cmd` هر سه کار را انجام می‌دهد. خاموش کردن همه‌چیز: `npm run down`.

نشانی ZX همیشه `http://127.0.0.1:39271/` است. اجرای مستقیم بدون راه‌انداز:

<div dir="ltr">

```bash
npm start -- --workspace D:\projects\my-app --port 39271 --no-open
```

</div>

## استفاده

- سایت را از فهرست بالا انتخاب کنید و کار را بنویسید؛ مثلاً «فایل‌های src را بگرد و توابعی که تست ندارند را فهرست کن».
- هر گام (پاسخ مدل، اجرای ابزار، خطا) روی خط عمودی صفحه دیده می‌شود. روی ابزار کلیک کنید تا خروجی یا diff آن را ببینید.
- **خواندن** خودکار است. **نوشتن و اجرا** طبق حالت مجوز (🛡 کنار جعبه‌ی پیام) کارت اجازه نشان می‌دهد. کلیدهای Y، A و N وقتی کار می‌کنند که در جعبه‌ای تایپ نمی‌کنید.
- «توقف» (یا Esc) کار جاری را قطع می‌کند و برنامه‌ی در حال اجرا را می‌بندد. Enter هیچ‌وقت کار را متوقف نمی‌کند.
- «تلاش دوباره» پیام شکست‌خورده را دوباره می‌فرستد. اگر کار وسط چند ابزار متوقف شده باشد، نتیجه‌ی همان‌هایی را که اجرا شدند می‌فرستد.
- زیر هر درخواست تعداد ارسال‌ها و «ارسال دوباره از اول» هست.
- پنل «فایل‌ها» زنده نشان می‌دهد کدام فایل در حال خواندن، نوشتن یا منتظر اجازه است.
- «گفتگوی تازه» در سایت هم گفتگوی تازه باز می‌کند و اجازه‌های «همیشه» را پاک می‌کند. عوض کردن پوشه یا سایت هم همین کار را می‌کند.
- ↑ و ↓ پیام‌های قبلی را برمی‌گردانند.
- ⓘ بالای صفحه: درباره‌ی برنامه، نسخه و سازنده.

### تب چت در پس‌زمینه

ZX تب سایت چت را هیچ‌وقت جلو نمی‌آورد. اگر تبی از آن سایت باز نباشد، یکی پشت تب فعلی شما باز می‌کند. بعضی سایت‌ها (DeepSeek، ChatGPT) در تب پنهان پاسخ را رسم نمی‌کنند. افزونه در صفحه‌ی آن‌ها کاری می‌کند که پاسخ در پس‌زمینه هم کامل بیاید. تب‌هایی که پیش از نصب افزونه باز بوده‌اند را یک بار بارگذاری دوباره کنید. اگر سایتی بعد از ۴۵ ثانیه هنوز چیزی ننوشته بود، خط وضعیت خبر می‌دهد و «نمایش تب» انتخاب خودتان است.

### چند مرورگر

اگر افزونه در چند مرورگر فعال باشد، فقط اولی به ZX وصل می‌ماند و بقیه منتظر می‌مانند. نام مرورگر وصل کنار «افزونه وصل» نوشته می‌شود. برای بردن ZX به مرورگر دیگر، در پنل کناری آن مرورگر «وصل کردن این مرورگر» را بزنید.

## ابزارهای مدل

| ابزار | کار | اجازه |
|---|---|---|
| `fs_list` | فهرست پوشه | خودکار |
| `fs_grep` | جست‌وجو در فایل‌ها | خودکار |
| `fs_read` | خواندن فایل، صفحه‌به‌صفحه | خودکار |
| `fs_write` | نوشتن یا ساختن فایل | طبق حالت مجوز |
| `fs_apply_diff` | جایگزینی دقیق یک تکه | طبق حالت مجوز |
| `exec` | اجرای `node` یا `git` فقط خواندنی | طبق حالت مجوز («ویرایش‌ها خودکار» هم می‌پرسد) |

همه‌ی ابزارها فقط داخل پوشه‌ی انتخاب‌شده کار می‌کنند و هر فراخوانی در لاگ ممیزی ثبت می‌شود (تنظیمات ← کارهای انجام‌شده).

## اگر کار نکرد

| نشانه | چه کنید |
|---|---|
| «افزونه وصل نیست» | مرورگر باز باشد و افزونه فعال و فعال‌سازی‌شده. بعد از روشن شدن برنامه تا ۳۰ ثانیه طول می‌کشد |
| «ZX در مرورگر دیگری وصل است» | افزونه در دو مرورگر فعال است. «وصل کردن این مرورگر» را بزنید یا افزونه را در یکی خاموش کنید |
| «could not find the message box» | وارد سایت شوید. بعد تنظیمات ← «بررسی سایت» تا ببینید کدام انتخابگر پیدا نمی‌شود |
| پیام نوشته شد ولی ارسال نشد | ZX خودش دو بار دیگر تلاش می‌کند. اگر نشد، «بررسی سایت» دکمه‌های کنار جعبه‌ی پیام را نشان می‌دهد؛ انتخابگر `send` را اصلاح کنید |
| پاسخ نیمه‌کاره گرفته شد | انتخابگر `stop` آن سایت را در تنظیمات درست کنید |
| «ZX خاموش است» | در پنل کناری «روشن کردن ZX» را بزنید، یا `zx-ai.exe` / `npm run up` را اجرا کنید |

انتخابگرهای هر سایت داده‌اند، نه کد: در تنظیمات به‌صورت JSON ویرایش می‌شوند و بدون ساخت دوباره اثر می‌کنند.

## بدانید

- **محتوای فایل‌هایی که مدل می‌خواند به همان سایت چت فرستاده می‌شود.** پوشه‌ای انتخاب کنید که فرستادنش مشکلی ندارد. از مسیر فقط نام پوشه فرستاده می‌شود.
- این روش به ظاهر سایت‌ها وابسته است. اگر سایتی ظاهرش را عوض کند، انتخابگرهایش باید به‌روز شوند.
- خودکارسازی حساب شخصی ممکن است با قوانین بعضی سایت‌ها هم‌خوان نباشد. ZX مثل یک انسان، در هر لحظه یک پیام می‌فرستد.
- سرور فقط روی `127.0.0.1` گوش می‌دهد و صفحه‌های وب دیگر به آن دسترسی ندارند. توکن ندارد، پس برنامه‌های دیگرِ روی همین کامپیوتر می‌توانند به آن وصل شوند.
- رمز فعال‌سازی جلوی استفاده‌ی اتفاقی را می‌گیرد، نه کسی را که کد را بخواند.

## مشارکت در توسعه

**هر برنامه‌نویسی که تمایل داشته باشد می‌تواند به توسعه‌ی این پروژه ملحق شود.** اگر ایده، گزارش اشکال یا کدی دارید:

1. در [Issues](https://github.com/Rashidizx/McpUseAI/issues) موضوع را مطرح کنید یا یکی از کارهای باز را بردارید.
2. مخزن را fork کنید، روی یک شاخه کار کنید و `npm run check` را سبز نگه دارید.
3. pull request بفرستید.

جزئیات در [CONTRIBUTING.md](CONTRIBUTING.md). کارهای باز در [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#کارهای-باز) فهرست شده‌اند، مثل آزمودن Gemini و Claude روی صفحه‌ی زنده، جدا کردن متن «thinking» و ابزارهای git نوشتنی.
